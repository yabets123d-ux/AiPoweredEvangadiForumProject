# AiPoweredEvangadiForum

# AI-Powered Community Discussion Workspace

AiPoweredEvangadiForumProject is a full-stack community forum project featuring a decoupled architecture, MySQL database integration, and Google Gemini AI context expansion.

## 🚀 Live Demo
**[Deployed Page](https://vercel.app)**

---

## 📁 Repository Structure
* **`frontEnd/`**: Client-side interface and state management.
* **`backEnd/`**: Core API server handling routes and AI integrations.

## ✨ Core Features
* Decoupled client-server architecture.
* Deep integration with the Google Gemini engine.
* Distributed Aiven MySQL cloud database support.

---

## 📦 Local Setup & Configuration

### 1. Initialize the Repository
```bash
git clone (https://github.com/yabets123d-ux/AiPoweredEvangadiForumProject.git)
cd AiPoweredEvangadiForumProject
```

### 2. Run the Backend
```bash
cd backEnd
cp .env.example .env
npm install
npm run dev
```

### 3. Run the Frontend
```bash
cd frontEnd
cp .env.example .env
npm install
npm run dev
```
